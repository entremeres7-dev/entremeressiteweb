# Désactiver la confirmation email (Supabase)

À faire **une fois** dans le dashboard Supabase :

1. **Authentication** → **Providers** → **Email**
2. Désactiver **« Confirm email »** (ou « Enable email confirmations »)
3. Enregistrer

Sans cette étape, les nouvelles inscriptions restent bloquées jusqu’au clic sur le lien reçu par mail.

L’app connecte automatiquement la maman après l’inscription lorsque cette option est désactivée.
